Texas Hold’em AoF Studio 3.0.0 升级说明
2026-09-05

本次交付
升级现有 Windows 离线 AoF 研究台，继续支持 2、3、4 人和按底池计算的抽水、封顶、无人跟注不抽水。游戏范围保持等筹码、无前注的翻前全下 / 弃牌，未扩展为完整翻后无限注德州。

算法与训练
保留实体牌条件分层采样及默认线性 CFR。实现标准 DCFR 和 2026 年 HS-DCFR(30)，提供 GUI / CLI 可选入口；每层采样数量可以调整。折扣使用稳定的数值表达式，保留有符号遗憾。HS 调度周期固定在检查点中，扩大训练预算时不会改变已经走过的训练过程。
检查点升级为 AOFCHK3，兼容读取旧 AOFCHK2。恢复核对人数、抽水、盲注、筹码、种子、算法、每层采样数与调度周期。线性 CFR、DCFR、HS-DCFR 的断点续训和不同物理线程数复现均已测试。GUI 支持完整 64 位随机种子。

独立精度评估
点击任意手牌即可将 10 万、100 万或 1000 万次新样本集中到该行动场景。结果包含 EV 差值、标准误、本次 99% 区间、预算、种子和策略指纹。不会修改原策略，也不会改写原文件的全局置信指标。
固定示例：内置四人 10 BB、3% 抽水策略，BB 面对 CO / BTN / SB 全下，JTs。原整表审计的有效样本约 36,642，EV 标准误 0.0817241 BB；新增 1,000,000 次单手评估、种子 20260905 后，有效样本约 959,627，标准误 0.0159335 BB。行动相对弃牌的 EV 为 -0.8803455 BB，本次 99% 区间 [-0.9403402, -0.8204439] BB。
这项比较使用新增的集中预算，两种区间控制的范围也不同，不能称为全表计算速度提高同样倍数。

独立底层校验
新增完全独立的五张牌排序参考实现。穷举 2,598,960 组五张牌，校验牌型分布、7462 个牌力等级及其顺序，再对 50,000 组七张牌穷举 21 个五张子集进行交叉校验。OMPEval 全部通过。
优化器在一个非对称、精确可解的双人零和矩阵博弈中验证。另保留抽水守恒、分池、牌冲突、合法范围质量、重要性权重、罕见范围和精确可解极端规则测试。

算法选型实测
四人、10 BB、3% 抽水。每种配置使用种子 2026、42、7；每次目标 3 亿训练采样、500 万全局评估及 5000 万条件审计，4 个工作线程。比较两种每层样本数，共 18 次实验。采样预算向上取整至完整轮次，计数单位为分层样本，不是完整牌局。
每层 4 样本，线性 CFR：偏离点估计均值 0.00173480 BB/手；99% 上界均值 0.13322356；训练及评估平均 17.35 秒。
每层 4 样本，DCFR：偏离点估计均值 0.03142296 BB/手；99% 上界均值 0.15602766；训练及评估平均 16.94 秒。
每层 4 样本，HS-DCFR：偏离点估计均值 0.03379093 BB/手；99% 上界均值 0.16374821；训练及评估平均 17.60 秒。
每层 64 样本，线性 CFR：偏离点估计均值 0.00184370 BB/手；99% 上界均值 0.13404413；训练及评估平均 15.10 秒。
每层 64 样本，DCFR：偏离点估计均值 0.01003979 BB/手；99% 上界均值 0.12818575；训练及评估平均 15.87 秒。
每层 64 样本，HS-DCFR：偏离点估计均值 0.01553982 BB/手；99% 上界均值 0.13880827；训练及评估平均 15.70 秒。
这些是当前模型、预算及机器上的有限实验，不代表其他筹码或更大预算。偏离点估计受采样噪声和最大值操作影响，保守上界仍明显更大。较新的折扣算法没有取得替代默认线性 CFR 的证据，因此默认设置保留线性 CFR，其他方法标为实验。内置六组十亿预算策略也继续使用原来经过评估的版本。
完整命令、种子、引擎 SHA-256、输出 SHA-256 和原始统计见 docs/benchmark-v3.json；最新论文及实现选择见 docs/research.txt。

桌面产品
策略分析、训练与日志、说明与来源三个页面。提供行动频率、EV 差值、判断确定性、两策略频率差异四种热图，混合手牌筛选、方向键导航、深浅主题、品牌图标和可复制的手牌详情。不同规则的策略对比会明确显示规则差异。常见笔记本分辨率下训练按钮固定可见，详情与范围并排。
训练历史使用本地 SQLite，记录命令、引擎指纹、结果指纹、状态和检查点。支持从记录载入结果、继续训练及打开目录；完整日志保存在本机，界面显示有长度上限的日志尾部。应用异常写入滚动日志。未增加遥测、账户或远程服务。

文件可靠性
新生成策略使用带 CRC-32 的 v3 容器，兼容 v1/v2。校验能识别仍在合法数值范围内的内容损坏；CRC 不是数字签名。内置旧策略另有 SHA-256 清单校验；训练记录核对结果指纹。策略和检查点继续原子保存。修复 Windows 大小写、别名以及临时输出路径冲突的校验。

依赖与发行
GUI 迁移到 PySide6 Essentials 6.11.2；构建工具更新到 PyInstaller 6.22.2，并固定经过测试的依赖版本。目录发行版提供可替换的 Qt 共享库、应用源码、Qt / PySide 对应源码、许可证、构建说明和所有发行文件的校验清单。另提供单文件便携启动程序。
本地测试为 49 项 Python 测试和 4 项 C++ 测试组。目录发行包已在隔离 PATH 下完成启动、三种人数策略载入、真实训练、检查点保存、CSV 导出、单手评估与训练记录验收。最终发行验收使用 tools/verify_release.py，可重复执行。
CI 增加 Linux ASan / UBSan 和手动触发的 Windows 打包验收。远程 CI 未在本次会话中实际运行，不能视为已通过的远程结果。

当前边界
这是经过本地验收的桌面研究产品升级，不是四人精确 GTO 证明，也尚未做商业代码签名或与独立商业求解器的对照认证。后续正式商业质量承诺需要明确可接受的偏离上限，在目标规则集上开展独立验证并完成发行签名。此次没有上传或发布到 GitHub。
